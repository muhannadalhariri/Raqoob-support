# Raqoob / راقوب support

Raqoob is a macOS utility for viewing CPU, GPU, memory, battery charge, network traffic, and thermal status. It includes a menu bar panel and a macOS widget.

## Help

For a bug or question, [open a support issue](https://github.com/muhannadalhariri/Raqoob-support/issues/new). Include your macOS version, Mac model, what you expected, and what happened. Do not post serial numbers, passwords, or private logs.

If a reading is unavailable, your Mac or macOS version may not expose it. Raqoob does not control fan speed or schedule work across CPU cores.

## Privacy

See the [privacy policy](PRIVACY.md).

# دعم راقوب

راقوب أداة لنظام macOS تعرض حالة المعالج والرسوميات والذاكرة وشحن البطارية وحركة الشبكة والحالة الحرارية، مع لوحة في شريط القوائم وأداة سطح المكتب.

للمساعدة أو الإبلاغ عن مشكلة، [افتح تذكرة دعم](https://github.com/muhannadalhariri/Raqoob-support/issues/new). اذكر إصدار macOS وطراز الجهاز وما توقعته وما حدث، وتجنب نشر الأرقام التسلسلية وكلمات المرور والسجلات الخاصة.
